# BGM dari Folder music/ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Game memutar semua file musik di `music/` (rekursif) sebagai BGM dengan antrian acak yang menyisipkan kembali lagu yang sudah diputar.

**Architecture:** Logika murni (`ShuffleQueue`, `MusicLibrary`, interface `IMusicPlayer`, `NullMusicPlayer`) berada di `src/core` tanpa audio. `MiniaudioPlayer` di `src/audio` membungkus miniaudio dan berjalan di thread pengelola sendiri. `main.cpp` merakit semuanya; `GameController` dan layar game tidak berubah.

**Tech Stack:** C++17, CMake FetchContent, miniaudio tag `0.11.22` (target CMake `miniaudio`), FTXUI v6.1.9, kerangka uji `tests/check.hpp`.

**Spec:** `docs/superpowers/specs/2026-11-23-bgm-musik-design.md`

## Global Constraints

- C++17; harus bisa dibangun di Linux dan Windows. Dependensi baru hanya miniaudio pada tag `0.11.22`.
- `src/core` dan `src/controller` tidak boleh memuat FTXUI, miniaudio, `rand()`, atau `srand`.
- Antrian musik memakai `Rng` sendiri; `Rng` milik `GameController` tidak boleh disentuh.
- Format yang dipindai (tanpa membedakan huruf besar/kecil): `.mp3`, `.wav`, `.flac`. Folder: `music/` relatif terhadap direktori kerja.
- Perilaku antrian: diacak tiap game dijalankan; lagu yang selesai diputar disisipkan kembali di posisi acak di antara lagu lain, tidak di depan.
- Thread UI tidak boleh menunggu musik; `stop()` harus kembali cepat. Callback akhir lagu (thread audio) hanya menaikkan bendera.
- Kegagalan musik (folder hilang, file rusak, tak ada perangkat suara) tidak boleh membuat game crash atau macet.
- Teks layar ASCII, bahasa Indonesia. Proyek bukan repo git: verifikasi per tugas = `ctest` penuh hijau (`cmake -S . -B build && cmake --build build && ctest --test-dir build --output-on-failure`).

## Review Focus

1. Folder `music/` hilang, kosong, atau hanya berisi file non-musik: tidak crash, status menu "tidak ada", game sunyi. (Task 2, 5)
2. File berekstensi `.mp3`/`.wav` yang isinya rusak: dilewati; bila semua rusak, tidak menggantung dan tidak memakai CPU terus-menerus. (Task 4)
3. Menekan Esc saat musik berjalan: `stop()` selesai dalam waktu singkat. (Task 4)
4. Tidak ada perangkat suara (mesin tanpa audio): game tetap jalan sunyi. Sandbox ini memang tanpa perangkat, jadi tes opsi bawaan menguji jalur ini. (Task 4)
5. Nama file berspasi dan non-ASCII (`lagu bagus ñ.wav`): terbaca dan diputar. (Task 2, 4)

**Interfaces:**
- Produces: `class ShuffleQueue { public: ShuffleQueue(std::vector<std::filesystem::path> items, Rng rng); std::optional<std::filesystem::path> next(); std::size_t size() const; };`
  Konstruktor mengacak dengan `std::shuffle`. `next()`: kosong -> `std::nullopt`; selain itu ambil lagu terdepan, lalu sisipkan kembali di indeks `randomBetween(rng_, 1, n)` dari `n` lagu yang tersisa (n = 0: tambahkan di akhir), sehingga tidak pernah kembali ke depan bila ada lagu lain. `size()` tidak pernah berubah oleh `next()`.

// 2 lagu: 50 pemanggilan next() -> tidak pernah sama dengan pemanggilan sebelumnya
// 1 lagu: next() selalu lagu itu
// kosong: next() == nullopt, size() == 0
// seed 1 vs seed 2 (5 lagu): urutan 5 pemanggilan pertama berbeda untuk setidaknya satu pasangan seed
// lagu yang sudah keluar muncul lagi sebelum 3 putaran penuh (5 lagu, 15 pemanggilan: ada lagu yang keluar >= 2 kali)
```

### Task 4: MiniaudioPlayer dan CMake miniaudio

- Produces: `struct MiniaudioOptions { bool useNullBackend = false; };` dan `class MiniaudioPlayer : public IMusicPlayer { public: explicit MiniaudioPlayer(ShuffleQueue queue, MiniaudioOptions options = {}); ~MiniaudioPlayer() override; void start() override; void stop() override; std::string nowPlaying() const override; };` Tidak dapat disalin. `nowPlaying()` mengembalikan nama berkas (tanpa folder) lagu yang sedang diputar, atau `""`; aman dipanggil dari thread lain.

Pustaka statis `rogue_audio` dari `src/audio/*.cpp` menautkan `rogue_core` dan `miniaudio`; `roguelike` menautkan `rogue_audio`; `add_rogue_test(player)` ditautkan ke `rogue_audio`. `rogue_warnings` hanya untuk target kita, bukan `miniaudio`.

// testSkipsCorruptFile: "rusak.wav" berisi byte acak + "bagus.wav"; nowPlaying() akhirnya "bagus.wav"

Pendekatan: satu `std::thread` pengelola; `ma_context` (backend `ma_backend_null` bila `useNullBackend`) + `ma_engine` dibuat di dalam thread atau `start()`; tiap lagu: `ma_sound_init_from_file(...
