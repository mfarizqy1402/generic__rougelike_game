Folder musik latar (BGM) generic_roguelike_game
=======================================

Letakkan berkas musik di folder ini (boleh di dalam subfolder):
  .mp3  .wav  .flac

Saat game dijalankan, semua lagu diacak lalu diputar satu per satu. Setelah
sebuah lagu selesai, lagu acak berikutnya diputar; lagu yang sudah diputar
masuk lagi ke antrian acak.

Catatan:
- Jalankan game dari folder proyek (tempat folder "music" ini berada).
- Folder kosong = game berjalan tanpa musik.
- Berkas yang rusak dilewati begitu saja.
